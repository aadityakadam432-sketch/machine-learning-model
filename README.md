# Week 4 - Machine Learning Model Development and Evaluation

## Project Overview

This project demonstrates the development and evaluation of a basic Machine Learning classification model using Python and Scikit-learn.

## Dataset

The Breast Cancer Wisconsin Diagnostic dataset is used for classification.

- Samples: 569
- Features: 30
- Problem Type: Binary Classification

## Machine Learning Algorithm

Logistic Regression

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib

## Data Preprocessing

- Train-test split
- Stratified sampling
- Feature scaling using StandardScaler

## Evaluation Metrics

The model was evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix
- ROC Curve

## Results

| Metric | Score |
|---|---:|
| Accuracy | 99.12% |
| Precision | 98.61% |
| Recall | 98.61% |
| F1-Score | 98.61% |
| ROC-AUC | 0.995 |
